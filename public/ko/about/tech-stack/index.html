기술 스택

기술 스택은 제품을 만들고 제공하는 데 사용하는 도구 모음입니다. TugQL은 SQL과 비슷한 텍스트 형식과 TugQT라는 구조화된 쿼리 트리를 가진 이식 가능한 쿼리 언어입니다.

이 웹사이트

작은 Node.js 생성기가 번역된 내용을 정적 HTML로 만듭니다. Cloudflare Workers Static Assets가 페이지를 제공하므로 운영 환경에 JavaScript 프레임워크가 필요하지 않습니다.

제품

공개 명세는 TugQL 텍스트 문법과 JSON/YAML 쿼리 트리를 정의하며 Apache 2.0 라이선스로 게시됩니다. Go 구현은 DALgo 저장소에 있습니다. TugQL 명세 · Apache 2.0 · DALgo Go 구현.

여기에서 사용하는 자체 도구
