Tecnologías

La pila tecnológica reúne las herramientas con las que se construye y publica un producto. TugQL es un lenguaje de consultas portátil con sintaxis parecida a SQL y un árbol estructurado, TugQT.

Este sitio web

Un generador pequeño en Node.js convierte el contenido traducido en HTML estático. Cloudflare Workers Static Assets sirve las páginas sin un framework JavaScript en producción.

El producto

La especificación abierta define la sintaxis de TugQL y su árbol de consultas en JSON/YAML. Se publica bajo Apache 2.0. La implementación en Go vive en el repositorio de DALgo. Especificación TugQL · Apache 2.0 · Implementación Go en DALgo.

Herramientas propias utilizadas aquí

DALgo aloja la implementación en Go. Los enlaces «Probar en DataTug» llevan una consulta de ejemplo al banco de trabajo interactivo de datos. DALgo · DataTug.
