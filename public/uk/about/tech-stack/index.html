Технології

Технологічний стек — це інструменти для створення й публікації продукту. TugQL — переносима мова запитів із текстовою формою, схожою на SQL, і структурованим деревом TugQT.

Цей сайт

Невеликий генератор Node.js перетворює переклади на статичний HTML. Cloudflare Workers Static Assets віддає сторінки без робочого JavaScript-фреймворку.

Продукт

Відкрита специфікація визначає текстовий синтаксис TugQL і дерево запитів JSON/YAML. Вона опублікована за ліцензією Apache 2.0. Реалізація Go міститься в репозиторії DALgo. Специфікація TugQL · Apache 2.0 · Реалізація Go у DALgo.
