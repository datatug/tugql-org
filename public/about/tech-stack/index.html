Tech stack

A tech stack is the set of tools used to build and deliver a product. TugQL is a portable query language with an SQL-like text form and a structured query tree, TugQT.

This website

A small Node.js generator turns localized content into static HTML. Cloudflare Workers Static Assets serves the pages; the site does not need a production JavaScript framework.

The product

The open TugQL language specification defines its text syntax and JSON/YAML query tree. It is published under Apache 2.0. Its Go implementation lives in the DALgo repository, where applications can parse and work with TugQL queries. TugQL specification · Apache 2.0 · DALgo Go implementation.

Our tools used here

DALgo hosts the Go implementation. The “Try in DataTug” links take an example query into DataTug, which is where this language meets an interactive data workbench. DALgo · DataTug.
