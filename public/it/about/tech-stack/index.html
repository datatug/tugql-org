Stack tecnologico

Uno stack tecnologico è l’insieme degli strumenti usati per creare e distribuire un prodotto. TugQL è un linguaggio di query portabile con testo simile a SQL e un albero strutturato, TugQT.

Questo sito web

Un piccolo generatore Node.js trasforma i contenuti tradotti in HTML statico. Cloudflare Workers Static Assets serve le pagine senza framework JavaScript in produzione.

Il prodotto

La specifica aperta definisce la sintassi testuale di TugQL e l’albero delle query in JSON/YAML. È pubblicata con licenza Apache 2.0. L’implementazione Go si trova nel repository DALgo. Specifica TugQL · Apache 2.0 · Implementazione Go in DALgo.

I nostri strumenti usati qui

DALgo ospita l’implementazione Go. I link «Prova in DataTug» aprono una query di esempio nel banco di lavoro interattivo per i dati. DALgo · DataTug.

Progetti correlati

Esplora DALgo per l’implementazione e DataTug per il banco di lavoro.
