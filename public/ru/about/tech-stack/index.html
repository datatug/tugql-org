Технологии

Технологический стек — набор инструментов, с помощью которых создают и публикуют продукт. TugQL — переносимый язык запросов с текстовой формой, похожей на SQL, и структурным деревом TugQT.

Этот сайт

Небольшой генератор на Node.js создаёт статический HTML из переводов. Cloudflare Workers Static Assets отдаёт страницы; для сайта не нужен JavaScript-фреймворк в рабочем окружении.

Продукт

Открытая спецификация определяет текстовый синтаксис TugQL и дерево запросов в JSON/YAML. Она опубликована под лицензией Apache 2.0. Реализация на Go находится в репозитории DALgo. Спецификация TugQL · Apache 2.0 · Реализация Go в DALgo.
