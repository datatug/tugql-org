Technik-Stack

Ein Technik-Stack umfasst die Werkzeuge, mit denen ein Produkt gebaut und bereitgestellt wird. TugQL ist eine portable Abfragesprache mit SQL-ähnlichem Text und einem strukturierten Abfragebaum, TugQT.

Diese Website

Ein kleiner Node.js-Generator erzeugt aus übersetzten Inhalten statisches HTML. Cloudflare Workers Static Assets liefert die Seiten ohne produktives JavaScript-Framework aus.

Das Produkt

Die offene Spezifikation definiert TugQLs Textsyntax und den Abfragebaum in JSON/YAML. Sie steht unter Apache 2.0. Die Go-Implementierung liegt im DALgo-Repository. TugQL-Spezifikation · Apache 2.0 · Go-Implementierung in DALgo.

Eigene Werkzeuge auf dieser Seite

DALgo beherbergt die Go-Implementierung. Die Links „In DataTug ausprobieren“ öffnen eine Beispielabfrage in der interaktiven Datenwerkbank. DALgo · DataTug.
