Teknoloji yığını

Teknoloji yığını, bir ürünü oluşturmak ve sunmak için kullanılan araçlardır. TugQL, SQL benzeri metin biçimi ve TugQT adlı yapılandırılmış sorgu ağacı olan taşınabilir bir sorgu dilidir.

Bu web sitesi

Küçük bir Node.js üreteci çevrilmiş içeriği statik HTML’ye dönüştürür. Cloudflare Workers Static Assets sayfaları üretimde bir JavaScript çatısı olmadan sunar.

Ürün

Açık belirtim, TugQL metin sözdizimini ve JSON/YAML sorgu ağacını tanımlar. Apache 2.0 ile yayımlanır. Go uygulaması DALgo deposundadır. TugQL belirtimi · Apache 2.0 · DALgo Go uygulaması.
