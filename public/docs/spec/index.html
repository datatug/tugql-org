JSON Schema download

Download schema.json (MIT license notice). This is an exact copy of DALgo's schema at commit 69da201. It describes the Go library's YAML serialization of the core relational read-only dal.StructuredQuery subset and declares JSON Schema draft 2020-12.

It does not validate every text parser authoring tree or prove that every backend executes every construct. Resolve a query against caller-authorized schemas and verify the target adapter's capabilities before execution.
